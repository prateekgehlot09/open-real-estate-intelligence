# OREIL Architecture (v0.1)

## Overview

OREIL is designed as a modular intelligence system for real estate decision-making.

---

## Core Layers

### 1. Data Layer
- Transaction datasets
- Rental contract data
- Market benchmarks

---

### 2. Validation Layer
- Yield validation model
- Projection gap analysis

---

### 3. Risk Layer
- Liquidity scoring
- Demand scoring
- Pricing risk model

---

### 4. Intelligence Layer
- Report generation
- AI-assisted analysis

---

## Flow

Input Data → Validation → Risk Scoring → Intelligence Output

---

## Future Expansion

- Multi-market integration
- API layer
- Real-time data ingestion
